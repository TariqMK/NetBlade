No administrator rights

Every tool works for a normal user. nmap runs with --unprivileged, so SYN scans and raw sockets are never needed.

One file to run

The Windows build is a single .exe. No installer and no services. Only your notes and settings stay, in your user profile.

See the real command

curl and nmap show the exact command they run. Copy it to a terminal and get the same result.

Nothing sent home

No telemetry, no tracking, no accounts. NetBlade goes online only when you run a tool or check for updates. Notes stay on your computer.

The whole kit, one shortcut away

Each tool sits in the sidebar. Press Ctrl 1 to Ctrl 0 to jump straight to it, and drag tools into the order you use them.

Ctrl 5 Multi-ping

Watch ten hosts at once

Every host is a tile. Green is up, amber is unstable, red is down. Each change lands in a log with the time, so a flapping printer can't hide.

Ctrl 4 curl

Know which phase is slow

Build a request from a form. NetBlade times DNS, connect, TLS, server and transfer, and marks the slowest.

    IPv4 and IPv6 details, binary view, splits and route summaries.

  8. Ctrl8

    TLS certificate

    Chain, trust, expiry and accepted TLS versions.

  9. Ctrl9

    Whois

    Owner, range and abuse contact of an IP, AS number or domain.

  10. Ctrl0

    The vendor of a MAC address, offline after one download.

    Scratch notes in a monospace font. Saved as you type.

  12. Sidebar

    Paste two texts and see the different lines, words or characters.
